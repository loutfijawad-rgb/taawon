# Taawon 🌾

Application web (installable sur téléphone) de gestion et de facturation pour les coopératives agricoles au Maroc.

- **Adhérents** : fiche, CIN, douar, téléphone WhatsApp
- **Collecte** : livraisons (L, kg…) au prix du jour, avances (aliment, engrais…)
- **Paiement des adhérents** : relevé par période (livraisons − avances − déjà payé), impression et envoi WhatsApp
- **Ventes** : factures numérotées aux acheteurs, ICE, TVA réglable, montant en lettres, PDF
- **Tableau de bord** et exports CSV pour le comptable

Les données restent sur l'appareil (localStorage). Fonctionne hors ligne une fois installée.

Application en ligne : https://charikafilahia.netlify.app — sur le téléphone, ouvrir le lien puis « Installer l'application » / « Ajouter à l'écran d'accueil ».
